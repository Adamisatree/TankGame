## 一、联机（A1–A7）

| # | 改了什么 | 现在的行为 |
|---|----------|-----------|
| A1 | 客机 `updateGuest()` 回写 `kills` / `deaths` / `damage`，HUD 标脏 | 客机血条栏、公告栏、记分板上的击杀数与房主一致 |
| A2 | 新协议 `result` 消息（房主 → 全房间，服务器原样转发）+ 客机 `applySnapshot()` 的 `matchOver` 兜底 | 房主结算时把胜者/原因/明细/用时/模式/队伍整包发出去；客机收到即出同一张结果卡。`result` 丢了也能从快照的 `matchOver` 重建。客机**不能**给房间下结论（服务器只转发房主的） |
| A3 | 开火冷却从两个标量 `fireCd1/fireCd2` 改成 `Map<tankId, number>` | 每台坦克自己的冷却：9 人房里谁按谁打，射速回到 0.75s/发 |
| A4 | 击杀时只清"死者自己的炮弹" | 别人（含队友、凶手）正在飞的炮弹不再凭空消失 |
| A5 | `weakenTarget()`：按 `canDamage()` 找最近的**合法**目标，找不到就不消耗冷却 | 单人模式点技能不再白费；团队赛不会弱化队友；乱斗打最近的对手 |
| A6 | 会话恢复：`join.session` + `joinOk.resumed`，服务器 `SESSION_TTL_MS = 120s` 内允许同一 session 拿回原座位；`room.started` 只在**新的**房主进场时才清 | 网络抖一下重连，座位/队伍/比分都还在，房间也不会被打回大厅 |
| A7 | 开火特效用 `NetEvent.angle` + 真实座位颜色 | 客机上每个座位的炮口烟方向、颜色都对 |

`npm run smoke`（p3/p4 独立冷却、客机回写战绩、只清死者炮弹、弱化只打合法目标）。

## 四、更新与安装（D1–D7）

| # | 改了什么 | 现在的行为 |
|---|----------|-----------|
| D1 | 安装时**复制**安装包到"下载"目录，`versions/` 里的存档保留；源码从存档路径启动；同名但大小不同的旧文件不覆盖（改名另存） | 装完还能在"本机已下载的版本"里看到这一版，降级不用重新下；用户自己留的安装包不会被删 |
| D2 | 三个漏洞一起补：① 缓存命中必须 sha 对得上，没摘要的缓存返回 `verified: false`；② `download.mjs` 结果带 `verified`；③ 没校验值的安装包，主进程**拒绝**静默安装，面板弹确认，用户同意才带 `allowUnverified` 重试 | 清单缺 sha256 时不再"静默装上一个没人校验过的 exe" |
| D3 | `update:download` 校验 URL：只认 https + GitHub / jsDelivr / **仓库自带的** `mirrors.json` 里的主机；安装前再按清单 sha 复核一次 | 清单或镜像被改写也指不到任意主机；摘要不符直接拦下 |
| D4 | `update:install-file` 的路径白名单补上分隔符（`dir + sep`） | `…/versions-x/evil.exe` 不再被当成"版本库里的文件" |
| D5 | 测速结果写进 `updater.json`（`probeRank` / `probeAt`），"自动（选最快）"按它排序候选，一小时后失效 —— 注释里承诺的缓存真有了 | 点过测速之后，下载真的走最快的那条线路 |
| D6 | 测速改成测**安装包下载路径**：取缓存清单里最新资产，带 `Range: bytes=0-1023` + 读完第一块就挂断（`measureLatency({ firstByteOnly })`） | 排名对应真实的下载链路，且不会因为镜像忽略 Range 而拉整个 160MB |
| D7 | 清单候选 URL 拼接时补全分隔符，空前缀直接跳过 | 以后往 `rawMirrors` 加一个不带 `@` / `/` 的前缀，也不会静默生成坏 URL |
| 附带 | `data-sha` 不再渲染成字符串 `"undefined"`（会让每次下载都 sha 不符） | 没有摘要的资产走"未校验"流程，而不是必然失败 |

回归：`npm run test:update`（82 项，含 `verified` 标记、首字节探测不会读满文件）。
