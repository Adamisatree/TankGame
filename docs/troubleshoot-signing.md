# 证书 / 签名 / 安装包问题排查（v1.5.1 及以后）

> **先说结论**：本项目**没有代码签名证书**（`mac.identity: null`，Windows 也没有买证书，
> 个人项目拿不到）。所以「证书损坏 / 证书无效 / 无法验证开发者」这一大类提示，
> 99% 不是"项目的证书过期了"，而是下面三件事之一：
>
> 1. **系统下载保护**（Windows SmartScreen / macOS Gatekeeper）对未签名程序的默认拦截；
> 2. **文件没下完整或被改动**（镜像断流、杀软改写、下载加速器、解压工具出错）；
> 3. **网络中间人**（公司/校园网 HTTPS 拦截、系统时间错乱）让 TLS 证书检查失败。
>
> 第 1 类：照对应小节点两下就好。第 2 类：**先核 sha256，不一致就别装**。第 3 类：换网络 / 换镜像。

## 0. 症状速查表

| 你看到的提示 | 真正的原因 | 去哪一节 |
| --- | --- | --- |
| Windows：「Windows 已保护你的电脑」/「无法验证发布者」 | SmartScreen 对未签名程序的拦截 | 2.1 |
| Windows：「Windows 无法验证此文件的数字签名」 | 同上：本来就没签名，不是坏了 | 2.2 |
| Windows：`0x800B0109` / `0x80096010` /「证书已被篡改」 | 文件被截断或被杀软改过 | 2.3 |
| Windows：NSIS「安装程序已损坏或不完整」 | 同上（下载不完整） | 2.4 |
| macOS：「已损坏，无法打开，你应该将它移到废纸篓」 | quarantine 标记，**不是**文件真坏 | 3.2 |
| macOS：「无法打开，因为 Apple 无法检查其是否包含恶意软件」 | Gatekeeper 未公证 | 3.1 |
| macOS / 浏览器：「证书无效」「连接不是私密连接」 | 镜像站 TLS 失败，或系统时间不对 | 3.5 / 4 |

| 局域网：进不去房间，提示版本不一致 | 两台机器版本不同（1.5.0 与 1.5.1 不能联机） | Q9 |

## 1. 先做 30 秒自检：sha256 对不对

每个安装包的**大小和 sha256** 都写在仓库的 `updates.json` 里：
<https://github.com/Adamisatree/TankGame/blob/main/updates.json>
（国内打不开 github 时，用镜像拿同一份文件：
`https://ghfast.top/https://raw.githubusercontent.com/Adamisatree/TankGame/main/updates.json`）

### Windows（PowerShell，不用管理员）

```powershell
$f = "TankGame-1.5.1-setup.exe"
"size  : " + (Get-Item $f).Length
"sha256: " + (Get-FileHash $f -Algorithm SHA256).Hash.ToLower()
```

### macOS / Linux

```bash
f=TankGame-1.5.1-arm64.dmg
echo "size  : $(stat -f%z "$f" 2>/dev/null || stat -c%s "$f")"
echo "sha256: $(shasum -a 256 "$f" | cut -d' ' -f1)"
```

把两个数字和 `updates.json` 里对应资产的 `sha256` / `size` 对一遍（大小写无所谓）：

- **完全一致** → 文件没问题，提示是系统下载保护，跳到第 2 或第 3 节；
- **对不上** → **别装**，删掉重下（换一个镜像、关掉 IDM/迅雷这类下载加速器、别用解压软件拆 exe/dmg）。

## 2. Windows

### 2.1 Windows SmartScreen

1. 弹窗上点「**更多信息**」；
2. 出现「**仍要运行**」→ 点它；
3. 紧接着可能还有一次 UAC「是否允许此应用对你的设备进行更改」→「**是**」。

这是 Windows 对"没有代码签名、下载量还不够"的程序的标准待遇，不是报错。

### 2.2 Windows 无法验证此文件的数字签名

**预期行为**，因为安装包本来就没有签名。看完第 1 节的 sha256 后正常安装即可。

### 2.3 Windows 错误码 0x800B0109 / 0x80096010

这两个码的意思是"系统信任链验证不过 / 内容摘要和签名不符"。对**未签名**的包来说，
它们几乎总是意味着**文件在磁盘上已经不是我们发布的那份了**：

- 下载被截断（镜像断流、代理超时）→ 重下，看第 1 节 sha256；
- 杀毒软件 / EDR 扫描时改写过文件 → 把安装包加入白名单后重下；
- 用了解压 / 改包工具 → 直接对原始 `.exe` 运行，不要解压；
- 从别人那里转手来的文件 → 重新从 Release 页下载。

排除以上仍然报错，就改用**便携版**（`TankGame-1.5.1-portable.exe`）或**单文件网页版**
（`TankGame-1.5.1-portable.html`），它们不写系统目录、不需要安装。

### 2.4 Windows 安装程序已损坏或不完整

NSIS 安装包被截断的典型提示。按 2.3 处理；如果反复出现：

- 换成单架构的 `TankGame-1.5.1-x64-setup.exe` 或 `-arm64-setup.exe`（体积小一半，断流概率低）；
- 或直接下 `-portable.exe`（免安装，双击即玩）。

### 2.5 装完了但打不开 / 一闪而过

- 先确认没有从压缩包里直接双击：安装包要先落到本地磁盘再运行；
- 卸载后重装一次（设置 → 应用 → 坦克大作战 → 卸载）；
- 地图和设置存在 `%APPDATA%\TankGame` 里，卸载**通常不会**删掉它们；想彻底重来再手动删这个目录。

## 3. macOS

### 3.1 macOS Gatekeeper 拦下未公证的应用

第一次打开会提示「无法打开，因为 Apple 无法检查其是否包含恶意软件」：

1. 「**系统设置 → 隐私与安全性**」，页面下方会有「已阻止使用 TankGame」→ 点「**仍要打开**」；
2. 或者按住 `Control` 点 App 图标 →「**打开**」→ 再点「打开」。

### 3.2 macOS 已损坏，无法打开

这句是 Gatekeeper 对"带 quarantine 标记 + 未签名"的说法，**不是文件真的坏了**
（先按第 1 节核 sha256，确认没坏再用下面命令）。

对下载的 dmg：

```bash
xattr -dr com.apple.quarantine ~/Downloads/TankGame-1.5.1-arm64.dmg
```

已经装进「应用程序」的：

```bash
xattr -dr com.apple.quarantine /Applications/TankGame.app
```

然后重新打开。

### 3.3 从 zip 解压后提示损坏

```bash
xattr -dr com.apple.quarantine ~/Downloads/TankGame-1.5.1-arm64.zip
unzip -o ~/Downloads/TankGame-1.5.1-arm64.zip -d ~/Applications
```

（M 系列芯片用 `arm64`，Intel 用 `x64`；下错架构也会表现为"打不开"。）

### 3.4 提示 code signature invalid

只有在你移动 / 改过 App 内部文件，或用第三方工具"优化"过之后才会出现。重新下载安装包即可。
实在要救急，可以就地做一次 ad-hoc 重签（不需要开发者账号，只是让系统认为签名结构完整）：

```bash
codesign --force --deep --sign - /Applications/TankGame.app
```

### 3.5 系统时间不对

时间 / 时区错了会让 **TLS 证书**被判成"尚未生效 / 已过期"，浏览器和更新器都会报证书错误：

```bash
sudo sntp -sS time.apple.com      # macOS
```

```powershell
w32tm /resync                     # Windows（管理员）
```

## 4. 浏览器里说镜像站证书无效

更新清单和安装包会走几个**第三方 GitHub 加速镜像**（`jsDelivr`、`ghfast.top`、`ghproxy.net`、
`gh-proxy.com`、`gh.llkk.cc` 等，见仓库 `mirrors.json`）。这些镜像偶尔：

- 自己的 TLS 证书过期 / 配错 → 浏览器报「您的连接不是私密连接」；
- 被公司或校园网 SSL 拦截 → 同样报证书错误（这种情况**任何** https 站点都可能中招）。

处理顺序：

1. 换一个镜像重试（`mirrors.json` 里任选一个，把 `https://ghfast.top/` 换成 `https://ghproxy.net/` 等）；
2. 用「游戏内更新面板 → 镜像测速」看哪条线路是 `×`，避开它；
3. 手机热点 / 家用网络重试（绕开公司网关）；
4. 都不行时用**便携 HTML**（不联网也能玩单人和本地双人）。

> 安全提示：镜像只是"帮你转发文件"的中转，**任何**镜像返回的字节都要和 `updates.json` 的
> sha256 对得上才算数——v1.5.1 起游戏内更新器会自动做这一步。

## 5. 游戏内更新面板说校验失败

v1.5.1 起的行为：

1. 下载完成后按 `updates.json` 里的 sha256 复核，**不符直接拒绝安装**，提示
   「安装包校验失败（sha256 不符），已阻止安装」；
2. 清单里**没有** sha256 的版本会先弹确认框（「没有官方校验值…仍然要运行它吗？」），
   点「取消」就停在"已下载"这一步，不会执行。

处理：

1. 清掉这一版的缓存：面板「本机已下载的版本」里能看到它；对应文件在
   `%APPDATA%\TankGame\versions`（Windows）/ `~/Library/Application Support/TankGame/versions`（macOS），
   删掉 `TankGame-*.exe` / `*.dmg` 即可（只删安装包缓存，不动地图和设置）；
2. 回面板点「镜像测速」，再重新下载；
3. 还失败就手动从 Release 页下载，按第 1 节核过 sha256 后直接运行。

## 6. 终极兜底：单文件网页版

`TankGame-1.5.1-portable.html`（约 1.7 MB，脚本 / 样式 / 素材全在里面，零外部依赖）：

- 双击用浏览器打开就能玩**单人闯关**和**本地双人**；
- 不进系统、不写注册表、不需要安装，**没有任何签名 / 证书环节**；
- 限制：浏览器不能当服务器，所以**建房 / 联机**仍需要桌面版。

## 7. 想彻底没有提示？

| 平台 | 需要什么 | 说明 |
| --- | --- | --- |
| Windows | OV / EV 代码签名证书（每年数百到数千元） | EV 才能较快建立 SmartScreen 口碑；普通 OV 仍会先被拦一段时间 |
| macOS | Apple Developer Program（99 美元 / 年）+ notarize | 只签名不公证，Gatekeeper 照样提示 |

**不建议**为了省事去 `spctl --master-disable`（关掉 Gatekeeper）或整体关闭 SmartScreen——
那会让整台机器对真正的恶意软件也不再设防。

# Q&A

### Q1. 这是病毒吗？为什么我电脑一直警告？

不是。没有代码签名 + 下载量小的程序，Windows SmartScreen 和 macOS Gatekeeper 默认就会拦。
这也是本项目在 README 里明写"安装包没有做代码签名"的原因。想更稳，按第 1 节核 sha256，
或直接用免安装的 `-portable.exe` / `-portable.html`。

### Q2. 为什么不去签个名？

没有证书。Windows 的企业代码签名证书和 Apple 的 Developer ID 都要付费实名申请，
个人开源小项目通常不做。所以官方给出的替代方案是：**发布 sha256 清单**（`updates.json`），
让你能自己验证文件是不是原版，而不是让你"相信"它。

### Q3. sha256 对上了，还是提示"无法验证签名"，能装吗？

能。sha256 一致 + 来源是本仓库 Release，就说明文件没被改过；剩下的提示只是"没签名"本身。
按 2.1 / 3.1 放行即可。

### Q4. sha256 对不上怎么办？

**不要安装**，直接删掉重下。常见原因：镜像断流（换镜像）、下载加速器 / 代理改写（关掉）、
杀软扫描时"修复"过文件（加白名单重下）、解压工具拆过 exe / dmg（对原始文件运行）。

### Q5. 装完提示文件损坏 / 一闪就退？

见 2.5（Windows）和 3.2（macOS）。先核 sha256，再按对应平台的 quarantine / 白名单处理。

### Q6. 杀软把 setup.exe 删了或隔离了？

把安装目录加入白名单后重下（或用 `-portable.exe`，它不写 Program Files，触发概率更低）。
如果杀软坚持拦截，用 `-portable.html` 单文件版：它就是一个网页，杀软通常不拦。

### Q7. macOS 提示"已损坏"，是不是包真的坏了？

绝大多数情况**不是**。这是 Gatekeeper 对"带 quarantine 标记 + 未公证"的说法，
执行 3.2 里的 `xattr` 命令即可。但要先核 sha256：真坏了（下载不完整）就该重下，而不是强行打开。

### Q8. 更新面板说校验失败，但从 Release 页手动下载就能装？

说明镜像返回的字节不对（缓存了别的版本，或中途被改写）。清掉 `versions` 目录里的这一版缓存
（见第 5 节），换镜像重下；或者手动下载 + 核 sha256 后直接运行。
装完这一版后，本机版本库里会保留安装包，之后换版本就不用再下了。

### Q9. 能不能只更新一台机器？

**联机不行，单机可以。** 服务器会拒绝版本不一致的客户端，你会看到
「版本不一致：房主 x.x.x，你是 y.y.y。请两边用同一版本。」——
因为 1.5.0 与 1.5.1 的联机协议不同，混着打会立刻不同步。
局域网开局前确认两台机器**版本号相同**（主菜单标题上方那行 `… · v1.5.1`）。

### Q10. 换回旧版本会丢地图和设置吗？

不会。地图库、键位、设置都在 `%APPDATA%\TankGame`（Windows）/
`~/Library/Application Support/TankGame`（macOS）里，跟可执行文件版本无关；
更新面板「本机已下载的版本」里点「安装」就能切回去，不用重新下载。

### Q11. 便携版 exe、单文件 html、安装版有什么区别？

| | 安装版（setup.exe / dmg） | 便携 exe | 单文件 html |
| --- | --- | --- | --- |
| 需要管理员 / UAC | 是 | 否 | 否 |
| 能建房联机 | ✅ | ✅ | ❌（浏览器不能当服务器） |
| 自动更新面板 | ✅ | ✅ | ❌ |
| 签名 / 证书环节 | 有（未签名 → 系统提示） | 有（同上） | **没有** |

### Q12. 公司电脑一律拦，能离线安装吗？

可以：在能上网的机器上下载 `setup.exe`（或 `-portable.exe`），顺便把对应版本的
`sha256` 抄下来；拷到目标机器后先 `Get-FileHash` 核对，再运行。完全离线也能玩单人和本地双人；
联机需要目标机器能收到局域网的 UDP 广播（同一 Wi-Fi、同一网段）。

### Q13. 我还是搞不定，需要提供什么信息？

请附上：系统版本（如 Windows 11 23H2 / macOS 14.5）、安装包完整文件名、第 1 节的两个数字
（size + sha256）、报错提示的**原文或截图**。有这三样，基本能一眼定位是"下载坏了"还是"系统拦截"。
