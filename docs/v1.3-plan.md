## 三、现状 vs 目标

| 项 | 现状（代码） | 目标 |
| --- | --- | --- |
| 操作 | `SeatAction` 里有 `left/right`（底盘）和 `aimLeft/aimRight`（炮口 Q/E）两套；`applyInput()` 里 `turnHull()` 与 `aimAt()` 分两步，还会互相踩 | **一套转向**，炮口固定在车体上随车体转；鼠标或单键只做瞄准（见待确认 1） |
| 射速 | `fireCd = 0.24s` | 放慢，建议 **1.1s/发**（狂暴技能另算） |
| 攻角 | `TURRET_LIMIT = 72°`，只在代码里夹，画面上看不出来 | 画一段**扇形弧线 + 端点刻度**，明示可打范围 |
| 伤害 | `damage(victim, attacker, amount = 1)` 只扣 1 条命 | 按**命中部位**扣血：前 7 / 侧 9 / 后 12 |
| 生命 | 心形 × 3 条命（`lives`），`HIT_MERCY = 1.1s` 无敌 | 全员 **100 血 + 血条**，无敌帧取消或极短 |
| 反弹 | `BULLET.maxBounces = 4` | **2 次**（沿用上一轮要求） |
| 模式 | `solo` / `versus`（本地 2P）/ `lan`（**1v1 中继**） | 增加 **LAN 乱斗 2–6**、**LAN 团队**；本地 2P 保留 |
| 服务端 | `room = { host, guest }`，只配对两个人 | `room = { slots[], mode, team[], config }`，N 人 + 队伍 + 房间上限 |
| 胜负 | 命数打光 | 人头目标 / 时间上限 / 平局 |
| 地图 | 8 张单屏图（1280×720 固定 `PLAY_RECT`） | 新增**多人大地图**（世界大于屏幕）+ **坦克缩小** |
| 复活 | 复活在原出生点，无选择 | 乱斗：远离所有活人的随机点；团队：**队友身旁**，无队友则随机 |
| 友伤 | 无概念（1v1） | 开局前两个独立开关：友伤、自伤 |
| 技能 | 房主可改别人的技能（`skillP2 = skill`） | 每人自选，只在公示区展示 |

## 四、改动清单（按批次，可分别验收）

### 批次 1 · 操作、射速、攻角

- [ ] **1.1 合并转向**：`SeatAction` 去掉 `aimLeft/aimRight`（迁移旧存档：键位文件加 `version: 2`，旧 `aimLeft/aimRight` 丢弃）。
- [ ] **1.2 炮口跟随车体**：`Tank.turnHull()` 后 `turretAngle = bodyAngle + turretOffset`；`applyInput()` 只调一次转向，不再"先算瞄准角再转底盘"。**这修掉了按 A/D 时炮管钉在原地的老问题**。
- [ ] **1.3 射速**：`config.ts` 加 `FIRE_COOLDOWN = 1.1`（用常量，不散落在场景里），`fireCd` 读它。
- [ ] **1.4 攻角可视化**：在车体下方画一段淡墨弧线（±`TURRET_LIMIT`），两端带小刻度；瞄准到边界时弧线端点变红。
- [ ] **1.5 输入协议**：`TankInput` 去掉"世界瞄准角"，改为 `aim` = 相对车体偏移（或 `turn` + `aimTrim`），联机两侧算法一致。
- [ ] 测试：`selftest` 校验"底盘转 N 度后炮管相对夹角不变"、"Q/E 不再存在"、"射速间隔 ≥ 1s"。

### 批次 2 · 血量与部位伤害

- [ ] **2.1 血量**：`Tank` 加 `hp / maxHp = 100`；删 `lives`；`damage()` 改成 `hp -= amount`。
- [ ] **2.2 部位判定**：`bullet` 命中时按入射方向与车体朝向的夹角分类 → **前 ±60° = 7**、**后 ±60° = 12**、**其余（两侧）= 9**。
- [ ] **2.3 部位反馈**：命中处冒不同颜色墨点 + 伤害数字（7/9/12）；HUD 血条按 10 段刻度。
- [ ] **2.4 无敌帧**：`HIT_MERCY` 取消（或压到复活保护 0.8s，见待确认 3）。
- [ ] **2.5 反弹 2 次**：`maxBounces = 2`，AI 求解深度同步。
- [ ] **2.6 道具适配**：医疗包 **+40 血**；护盾「6 秒 + 只挡 1 次」，挡完立刻消失。
- [ ] **2.7 单人数值**：AI 也 100 血，难度改为调 AI 精度/反应/射速，不再调"敌人几条命"。
- [ ] 测试：`selftest` 部位伤害表、护盾一次消耗、医疗包上限、10 发打死。

### 批次 3 · 模式与房间（本轮最大改动）

## 五、需要你拍板的 5 个点

1. **"去掉转地盘和炮口"到底去掉哪一层？**
   - (a) **炮口彻底固定在车体上**：只有左右转向，车头朝哪就打哪（最干脆，配合车尾红点正好）
   - (b) **保留炮口可以在车体上偏转**，但只用鼠标瞄，不再有 Q/E 那套双键
   我倾向 (b)：能瞄又能保留"攻角范围"的展示意义；如果你要 (a)，那"攻角"就是 0°，弧线就没意义了。**选一个**。
2. **射速具体多慢**：1.0s/发（每分钟 60 发）还是 1.5s/发（每分钟 40 发）？配合"100 血 / 7–12 伤害"，1.0s 大概要 8–14 发打死一个人。
3. **无敌帧**：彻底删，还是保留"**复活后 1 秒**保护 + 受击无保护"？（建议后者，不然刚复活就被堵）
4. **复活要不要手动选点**：上一轮你说"死了可以直接选择复活到随机复活点"，这一轮团队说"复活在队友身旁"。我的方案是**自动分配**（乱斗挑远离活人的点，团队挑队友身旁），不弹面板。要手动选就得多一层 UI。
5. **团队复活在"队友身旁"**：是"紧贴队友（约 1 个车身）"，还是"离队友最近的安全点（可能在地图另一边）"？前者有堵人风险，后者更安全但可能很远。

## 九、1.3.1（UI 与手感）

  现在传 `atan2(vy, vx)`，倍率单独走一个参数；**顺带修好狂暴的双倍伤害**（之前被丢掉了）。
- **反弹统一 2 次**：AI 原来吃 `preset().maxBounces + 1`，困难档会打出 4 次反弹的炮弹，现在所有人一致。
