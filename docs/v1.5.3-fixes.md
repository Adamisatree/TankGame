# 1.5.3 —— 手感、信息与网络的三件事

这一版没有新玩法，全部是「用起来别扭的地方」：屏幕乱抖、看不到自己的技能 CD、
暂停里改不了设置、个别按钮点下去像没反应、内测面板吃掉 WASD、联机流量太胖。
下面每条都写清楚**以前是什么样、现在是什么样、怎么验证的**。

---

## 1. 敌人掉血不再晃你的屏幕

**以前**：任何一台坦克受伤都会触发同一套受击特效——`applyDamage()` 里不看是谁挨打，
相机直接 `shake()` + 闪白。十人房里别人互相打，你的画面跟着抖个不停，根本瞄不准。

**现在**：只有**你自己**的坦克受伤才会有震屏和闪白。别人掉血、木箱被打碎、
客机上别人中弹，都只留原有的火花 / 烟圈粒子，画面一动不动。

- 位置：`src/game/GameScene.ts` 的 `applyDamage()`、`onNetEvent()`。
- 顺手也修了客机：`hit` 事件以前只要收到就抖，现在是 `settings.hitEffects && ev.id === localTank().id`。

## 2. 设置里可以关掉受击特效

**以前**：没有开关，只能忍。

**现在**：菜单 →「设置」→ **受击特效**（复选框，默认开）。关掉之后自己挨打也不抖，
特效层立刻清掉（不用等这一段抖完）。开关是 `settings.hitEffects`，存在本机，
**整局中途也能改**——暂停界面里就有同一个开关，改完立刻生效（`GameScene.setHitEffects()`）。

## 3. 召唤师技能 CD 显示在屏幕右上角，且只显示自己的

**以前**：技能好了没有完全靠感觉；有的版本把所有人的技能状态一起写进 HUD，
十人房里右上角挤成一片（既没用，也等于把别人的技能冷却泄露给对手）。

**现在**：右上角一张 166×26 的小卡片：技能名 + `就绪` / 剩余秒数 + 底部一条进度条。

- **只画本机操控的座位**：单人 / 联机各一行（就是你自己）；本地双人各一行（两个手柄都在这一台机器上）。
- 联机里**永远看不到别人的 CD**——快照只带每个人自己的技能就绪时间，渲染也按 `localTank()` 过滤。
- 卡片是独立的 `Graphics` 层（深度 42/43），不跟着 HUD 的重绘节流，倒计时每帧都在走。
- 位置：`GameScene.refreshSkillChip()`。

## 4. 联机快照改成增量（协议 v10）

**以前**：30 Hz 全量快照，每台坦克 18 个字段整包发，十人房里大部分带宽都花在重复的
`"hp":100,"kills":0,"shield":0,…` 上。

**现在**：只发**变了的**东西，每秒（以及房间结构变化时）补一个关键帧：

| 内容 | 怎么省 |
| --- | --- |
| 比赛级字段（`phase` / `level` / `crates` / `matchOver`…） | 只在关键帧或真的变了时出现 |
| 木箱 | 变成一行 `0/1`，串起来比对，没变就不发 |
| 道具 | 按 `kind+respawn` 做键，只发变化 |
| 坦克 | 逐字段 diff（`TANK_WIRE_KEYS`），没变就不出现；`id` 只在换人时出现 |
| 炮弹 | 坐标量化到 0.1 像素、速度取整，`dmg` 只有不等于 1 才发 |

安全措施（这是「不能因此出错」的那一半）：

- WebSocket 本身有顺序、不丢包，增量不会错位；
- **每秒一个关键帧**（`kf: 1`），中途加入的人最多一秒就对齐；
- 换地图、有人进房、再来一局都会 `requestKeyframe()`；
- 快照字段全部是**可选**的，客机把「没出现」解释成「没变」，缺字段不会崩；
- 协议号 9 → **10**，1.5.2 与 1.5.3 联机会被版本锁挡在门外，不会出现一半按新规则、
  一半按旧规则。

`scripts/smoke.ts` 里加了三条断言：客机收到的流里**既有**关键帧也有增量、
关键帧一定带齐比赛级字段、增量里这些字段缺席。

## 5. 暂停界面里也有设置

**以前**：想关受击特效 / 开自动躲弹，必须退出这一局回菜单。

**现在**：暂停卡（P / Esc）里第一块就是「设置 · 改完立刻生效」——受击特效、自动躲弹
（联机时自动躲弹置灰，跟菜单一致）。点击立即写进设置**并推给正在跑的场次**
（`setHitEffects()` / `setAutoDodge()`），不用重开。

## 6. 「摁了没反应」的按钮全部修掉

| 按钮 | 以前 | 现在 |
| --- | --- | --- |
| 暂停 → 重新开始 | 清了画面但 `paused` 还在，遮罩消失后战场依旧冻结 | `restartGame()` 先复位 `paused`，并把结算锁存、计时器一起清掉 |
| 暂停 → 退出对局 | 已修（v1.5.0 起只由 `main.ts` 换场景），本版补了联机时的座位号 | 退出时用**自己的座位号**发 `surrender`（以前固定写 `p2`） |
| 菜单 → 开始游戏 | 在输入框里按回车 / 空格也会触发开局 | 焦点在输入框 / 文本域 / 下拉框里时不再当成开局 |
| 结算卡「等房主再来一局」 | 灰按钮，点了没反应 | 改成一行说明文字，不再假装是按钮 |
| 暂停 → 重新开始（访客） | 灰按钮 | 去掉，改成底部提示「重新开始由房主决定」 |
| 内测面板展开 | 展开后不滚动，看不全 | 展开时把面板滚进视野 |

## 7. 内测面板不再吃掉游戏里的按键

**以前**：内测输入框（数字框、`#tune-pass` 之类）一获得焦点，W / A / S / D 照样进 Phaser，
一边调参数一边坦克乱开；有的字段还会把 `P`（暂停）吃掉。

**现在**：

- 场景每帧检查 `document.activeElement`，焦点在 `INPUT / TEXTAREA / SELECT / contenteditable`
  上时**主动 `removeCapture`**，并重置所有按键状态（松开时不残留「按住」），离开后自动收回；
- `keyDown()` / `keyJustDown()` 在这种状态下直接返回 `false`，暂停 / 静音 / 自动躲弹的全局热键也一起让路；
- 面板自己还给每个滑杆、导入文件框加了 `keydown/keyup/keypress` 的 `stopPropagation()`（双保险）。

## 8. 内测面板不再要密码

**以前**：`TUNING_PASSWORD`（默认写死在源码里，还写在 README 上）挡着，输错了只报一句错。

**现在**：整个密码门删除——`isTuningUnlocked` / `unlockTuning` / `lockTuning` / `#tune-pass` /
`#tune-error` / 「重新锁定」按钮全部不复存在，点开就能改。

- `scripts/selftest.ts` 反向断言：模块里**没有** `TUNING_PASSWORD`，且不带任何凭据也能 `setTuning()`。
- 内测数值照旧随房间配置广播，房主可改、访客只读。

## 9. 仓库和 README 里不再出现内测口令

README 的「内测调参（需要密码）」一节改成「内测调参」并写明**没有密码**；
`scripts/verify-singlefile.ts` 的对应检查从「面板被锁住」改成「面板没有密码框」。
1.4.0 的旧发布说明里还留着一句口令，本版一并改掉了。

## 10. 版本

`package.json` / 打包版本号 → **1.5.3**；协议 **v10**；1.5.2 ↔ 1.5.3 联机被版本锁挡下，请两边一起更新。
